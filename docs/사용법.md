# HRA 보고서 도구 사용법

## 준비
1. 받은 `HRA_Tool` 폴더(또는 zip을 푼 폴더)를 원하는 곳에 둡니다. 설치할 것은 없습니다.
2. 폴더 안의 **`HRA_Tool.exe`** 를 실행합니다.
   - 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요. (서명하지 않은 프로그램이라 뜨는 안내입니다)

## 1. 보고서 서식 고치기
- **가장 쉬운 방법**: hwp/hwpx 파일을 `HRA_Tool.exe` 아이콘 위에 끌어다 놓기.
- 또는 창의 **[서식 교정]** 탭 → **파일 추가** → **고치기**.

결과는 **원본이 있는 폴더 안의 `결과` 폴더**에 생깁니다. 원본은 바뀌지 않습니다.
- `이름_피드백.hwpx` — 고친 문서 (고친 곳마다 메모)
- `이름_변경내역.txt` — 무엇을 고쳤는지 목록

한글로 `_피드백.hwpx`를 열어 메모를 확인하고, 필요하면 직접 마무리하세요.

## 2. 합본 만들기
1. **[합본]** 탭 → 확인을 마친 파일들을 **파일 추가**.
2. **▲ ▼** 로 합칠 순서를 맞춥니다.
3. **참고 합본**: 지난 합본 hwpx 파일을 한 번 골라 두면 다음부터 기억합니다. (표지·일정표를 여기서 가져옵니다)
4. **날짜** 입력 (예: `2026.11.07.(토)`, 비우면 빈칸) → **합본 만들기**.

결과: 첫 번째 파일이 있는 폴더의 `결과\합본_날짜.hwpx`
- 일정표에는 **도서명만** 채워집니다. **발표자·특강 내용은 직접 입력**하세요.
- 메모는 모두 빠집니다. 문서가 없는 세션(예: 경영서가 없는 날)은 일정표에서 빠집니다.

## 3. 메일로 온 파일 자동으로 고치기 (네이버)
### 처음 한 번만 할 일 (네이버 설정)
1. 네이버 메일 → 왼쪽 아래 **[환경설정]** → **[POP3/IMAP 설정]** → **IMAP/SMTP 사용: 사용함** → 저장.
2. 네이버 **[내정보] → [보안설정] → [2단계 인증]** 을 켭니다. (켜져 있어야 다음 단계가 됩니다)
3. 같은 화면의 **[애플리케이션 비밀번호 관리]** 에서 종류 "직접 입력"(예: HRA도구)으로 **비밀번호를 생성**하고, 나온 비밀번호를 복사해 둡니다.
   - 이 비밀번호는 이 도구만을 위한 것입니다. 잃어버리거나 그만 쓰려면 같은 화면에서 삭제하면 됩니다.
   - 네이버 로그인 비밀번호는 넣지 마세요.

### 도구에서
1. **[메일 자동 교정]** 탭 → 네이버 아이디(@ 앞부분), 애플리케이션 비밀번호, 저장 폴더 입력 → **설정 저장**.
2. **지금 확인**을 누르면 새 메일의 hwp/hwpx 첨부를 내려받아 고칩니다.
3. 창을 켜 두고 자동으로 하려면 **"자동 확인"** 을 켜고 간격(분)을 정합니다.

결과 위치 (기본: `문서\HRA메일`)
- `받은파일\날짜\보낸사람_파일이름` — 내려받은 원본
- `결과\날짜\파일이름_피드백.hwpx` — 고친 문서
- `처리기록.csv` — 언제 누가 보낸 무엇을 고쳤는지 (엑셀로 열림)

알아 둘 것
- **답장은 보내지 않습니다.** 확인한 뒤 직접 보내세요.
- 메일을 '읽음'으로 바꾸지 않습니다. 한 번 처리한 메일은 다시 처리하지 않습니다.
- 처음 설정한 날 들어온 메일부터 처리합니다 (예전 메일은 건드리지 않음).
- 창을 꺼 둬도 자동으로 하려면: 윈도우 **작업 스케줄러** → 기본 작업 만들기 → 매일, 반복 간격 10분 → 프로그램: `HRA_Tool.exe`, 인수: `--mail-check`. (기록: `문서\HRA메일\자동확인기록.txt`) 컴퓨터가 켜져 있어야 합니다.
- 설정(아이디·비밀번호)은 이 컴퓨터의 `%APPDATA%\HRA보고서도구\mail.ini` 에만 저장됩니다.

## 자주 묻는 것
- **hwp로 저장하고 싶어요** → 한글에서 열고 [파일 → 다른 이름으로 저장 → 한글 문서(*.hwp)].
- **고치면 안 되는 곳까지 고쳤어요** → `_변경내역.txt`의 해당 줄을 알려 주세요. 규칙을 고치겠습니다.
- **열리지 않아요 / 오류가 나요** → 창 아래 기록 칸의 내용을 캡처해 알려 주세요.
