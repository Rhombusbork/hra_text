# HRA 보고서 도구 사용법

> 배포판(10단계) 기준 초안입니다. 배포판이 나오면 화면에 맞춰 고칩니다.

## 준비
1. 받은 `HRA보고서도구.zip`을 원하는 곳에 풉니다. (설치할 것은 없습니다)
2. 폴더 안의 **`HRA보고서도구.exe`** 를 실행합니다.

## 1. 보고서 서식 고치기
1. **[서식 교정]** 탭에서 **파일 추가**를 누르거나, 받은 hwp/hwpx 파일을 창에 끌어다 놓습니다.
2. **고치기**를 누릅니다.
3. 원본과 같은 폴더의 `결과` 폴더에 두 파일이 생깁니다.
   - `이름_피드백.hwpx` — 고친 문서. 고친 곳마다 메모가 달려 있습니다.
   - `이름_변경내역.txt` — 무엇을 고쳤는지 목록.
4. 한글로 `_피드백.hwpx`를 열어 메모를 확인하고, 필요하면 직접 마무리합니다.

원본 파일은 바뀌지 않습니다.

## 2. 합본 만들기
1. **[합본]** 탭에서 확인을 마친 파일들을 추가합니다.
2. **▲ ▼** 버튼으로 합칠 순서를 맞춥니다.
3. 날짜를 입력합니다. (예: `2026.11.07.(토)`, 비워 두면 빈칸)
4. **합본 만들기**를 누르면 `결과/합본_날짜.hwpx`가 생깁니다.
   - 표지·일정표는 기본 양식을 씁니다. 일정표에는 도서명만 채워지니 **발표자·특강 내용은 직접 입력**하세요.
   - 메모는 모두 빠집니다.

## 자주 묻는 것
- **hwp로 저장하고 싶어요** → 한글에서 열고 [파일 → 다른 이름으로 저장 → 한글 문서(*.hwp)].
- **고치면 안 되는 곳까지 고쳤어요** → `_변경내역.txt`의 해당 줄을 알려 주세요. 규칙을 고치겠습니다.
- **열리지 않아요** → 오류 화면을 캡처해 알려 주세요.
