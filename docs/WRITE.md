# hra-write: 원고(.md) → 보고서(hwpx) 만들기

Claude 가 한글 보고서(고전·경영서·기업실무 텍스트)를 **새로 쓸 때** 쓰는 도구. hwpx XML 을 직접 읽고 고치면 토큰이 많이 드므로,
Claude 는 **마크다운 원고만** 쓰고, 서식은 잘 고쳐진 기존 보고서(틀)를 복제해 입힌 뒤 `hra-fix` 로 마무리한다. [U] 2026-11-17

## 순서

1. 같은 종류의 잘 고쳐진 보고서(`…_수정본.hwpx`)를 틀로 고른다. 예: 고전 → `~/hra/classic/HRA20_송채은-고전(햄릿)(1)_수정본.hwpx`.
   틀 hwpx 는 학생 이름이 있으니 저장소에 넣지 않는다.
2. 원고 `.md` 를 쓴다 (아래 형식). 그림은 원고 옆 폴더에 두고 상대 경로로 적는다.
3. `hra-write <틀.hwpx> <원고.md> -o out/<파일명>.hwpx`
4. `hra-fix fix out/<파일명>.hwpx -o out` → `_수정본.hwpx` 가 제출본, `_변경내역.txt` 로 확인.
5. 한글에서 열어 그림 크기·쪽 나눔만 눈으로 확인.

틀을 hwpx 로 열어 보지 않아도 된다. 확인이 필요하면 `hra-fix dump` 결과만 본다 (XML 을 읽지 않는다).

## 원고 형식

```
---
제목: 리바이어던              # 표지 큰 제목
소속: HRA 20기 1조            # 표지 정보 표 1~4행 오른쪽 칸 (틀의 행 순서: 소속, 발표자, 담당교수, 발표일)
발표자: 약학과 2학년 허영준
담당교수: ○○○ 교수님
발표일: 2026. 11. 21. (토)
---
# Ⅰ. 작품 및 작가 소개        → H1 (검은 띠 표). 목차는 H1 목록으로 자동
[소개: 리바이어던 | 자료/book.jpg]   → 소개 표 (제목 칸 + 그림 칸 + 본문 칸)
본문 문단…                    → 소개 표 본문
> 출처: …                      → 소개 표 안 출처(8pt 오른쪽)
[/소개]
## 1. 당시 배경               → H2 (숫자. 으로 시작)
### 1) 정치적 배경            → H3
#### ① 엘리자베스 1세         → H4
본문 문단                     → BODY (한 줄 = 한 문단)
> 출처: …                      → 출처 문단
<!-- 주석 -->                 → 무시
```

- 빈 줄은 구분용일 뿐이다. 제목(H1~H4)·소개 표 앞에 빈 문단 하나를 자동으로 넣고, 문단 사이 빈 줄은 `hra-fix` R18 이 맞춘다.
- 그림(jpg/png)은 틀 그림 칸의 가로 폭에 맞추고 세로는 비율대로. 틀의 옛 그림(BinData)은 지운다.
- 표지의 ■ 분류 줄은 틀 그대로다. 종류가 다르면 같은 종류의 틀을 쓴다.

## 아직 안 되는 것

- 본문 표(`| a | b |`) 는 지원하지 않는다. 필요하면 H4 목록으로 쓰거나, 만든 뒤 한글에서 넣는다.
- 굵은 글씨·기울임 같은 글자 일부 서식.
- 틀의 역할 찾기: 첫 `Ⅰ.` H1 표 바로 다음 표를 소개 표로, 그 뒤 처음 나오는 `1.`/`1)`/`①`/`출처`/본문 문단을 각 역할의 본보기로 쓴다. 틀이 이 모양과 다르면 `write.py` 의 "틀 문단 고르기" 부분을 고친다.
