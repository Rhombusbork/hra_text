# HRA 보고서 서식 규칙 (FORMAT_RULES)

이 문서는 프로그램이 **무엇을 검사하고, 어떻게 고치고, 어떤 메모를 다는지**를 정의하는 단일 기준(Single Source of Truth)이다.
코드는 이 문서를 따른다. 규칙을 바꾸려면 **이 문서를 먼저 고치고** 코드를 고친다. (자세한 절차: [CLAUDE.md](../CLAUDE.md) "문서-코드 동기화 규칙")

- 근거 표기: `[T]` 양식 템플릿(HRA20_0조-경영서/기업실무, HRA20_OOO-고전), `[F]` 사용자 피드백 메모(경영서 _피드백.hwpx), `[D]` 사용자 수정 전후 비교(기업실무 재제출→최종), `[U]` 사용자 직접 지시
- 상태: `계획` → `구현` → `검증`(샘플 회귀 테스트 통과)

## 0. 용어 정리

| 용어 (한글 프로그램) | 단축키 | 의미 | HWPX XML 위치 |
|---|---|---|---|
| **스타일** | F6 | 글자 모양 + 문단 모양을 묶어 이름 붙인 것. "바탕글"은 **스타일 이름**이다 | `hp:p@styleIDRef` → `header.xml hh:style@name` |
| **글자 모양** | Alt+L | 글꼴, 글자 크기, 진하게(볼드) 등 | `hp:run@charPrIDRef` → `hh:charPr` |
| └ 글꼴 | | 맑은 고딕 등 | `hh:charPr/hh:fontRef@hangul,latin,...` → `hh:fontface/hh:font@face` |
| └ 글자 크기 | | pt × 100 (10pt = `1000`) | `hh:charPr@height` |
| └ 진하게 | Ctrl+B | | `hh:charPr/hh:bold` 요소 존재 여부 |
| **문단 모양** | Alt+T | 정렬, 들여쓰기, 여백, 문단 위/아래 간격, 줄 간격 | `hp:p@paraPrIDRef` → `hh:paraPr` |
| └ 정렬 | | 양쪽/왼쪽/가운데/오른쪽 | `hh:paraPr/hh:align@horizontal` = `JUSTIFY`/`LEFT`/`CENTER`/`RIGHT` |
| └ 들여쓰기(첫 줄) | | **pt × 200** (10pt = `2000`) ※ 샘플로 확인됨 | `hh:margin/hc:intent@value` |
| └ 왼쪽/오른쪽 여백 | | pt × 200 | `hc:left`, `hc:right` |
| └ 문단 위/아래 간격 | | pt × 200 | `hc:prev`, `hc:next` |
| └ 줄 간격 | | % | `hh:lineSpacing@type="PERCENT" @value` |
| **글자처럼 취급** | 개체 속성 | 표/그림이 글자 한 개처럼 줄 안에 놓이게 하는 옵션 | `hp:tbl/hp:pos@treatAsChar`, `hp:pic/hp:pos@treatAsChar` = `1` |
| **쪽 나누기** | Ctrl+Enter | 문단을 다음 쪽에서 시작 | `hp:p@pageBreak="1"` |
| **메모** | 입력 > 메모 | 본문 범위에 다는 코멘트 | `hp:ctrl/hp:fieldBegin@type="MEMO"` … `hp:fieldEnd` |

> 예: "출처는 **바탕글 스타일**, **글꼴** 맑은 고딕, **글자 크기** 8pt, **정렬** 오른쪽"

## 1. 문단 역할(Role) 분류

모든 규칙은 "이 문단이 무엇인가"에 따라 기대값이 다르다. 먼저 역할을 분류한다.

| 역할 ID | 이름 | 판별 기준 (우선순위 순) | 근거 |
|---|---|---|---|
| `CATEGORY` | 분류 표시 | 문서 첫 문단, `■`로 시작 (■ 경영서 / ■ 기업실무 / ■ 고전명작) | [T] |
| `COVER_TITLE` | 표지 제목 | 첫 쪽, 가운데 정렬, 가장 큰 글자(≈32pt) 문단 | [T] |
| `TOC` | 목차 | "목차" 표 안 | [T] |
| `COVER_TABLE` | 표지 정보 표 | 소속/조원/발표자/담당교수/발표일 표 | [T] |
| `H1` | 1단위 타이틀 | `Ⅰ.`~`Ⅹ.` (로마숫자)로 시작. 템플릿에선 표 안에 있음 | [T] |
| `H2` | 2단위 타이틀 | `^\s*\d+\.\s` (예: `1. `) | [T] |
| `H3` | 3단위 타이틀 | `^\s*\d+\)\s` (예: `1) `) | [T] |
| `H4` | 4단위 타이틀 | `^\s*[①-⑳]` | [T] |
| `BODY` | 본문 | 위에 해당하지 않는 일반 텍스트 문단 | [T] |
| `SOURCE` | 출처/각주/참고자료 | `^\s*(출처|참고자료)\s*:` 또는 `[n]` 각주 목록 | [T][F] |
| `AUTHOR_TAG` | 작성자 표기 | `<…작성자: …>` | 샘플 |
| `TABLE_CELL` | 표 안 문단 | 표 셀 내부 (표지/목차/H1 표 제외) | [D] |
| `OBJECT` | 표/그림 개체를 담은 문단 | `hp:tbl` 또는 `hp:pic` 포함 | [T][F] |
| `EMPTY` | 빈 줄 | 텍스트 없음 | [F] |
| `REFLECTION` | 느낀 점/소감 블록 | 사람 이름 단독 문단 + 이어지는 본문 (경영서 끝부분) | 샘플 (Q 참고) |

## 2. 규칙 목록

각 규칙의 형식은 다음과 같다. **ID / 대상 역할 / 기대값 / 감지 / 수정 / 메모 템플릿 / 근거 / 상태**

### R01. 스타일은 전부 "바탕글"
- 대상: 전체 (메모 내부 제외)
- 기대값: `styleIDRef` → `바탕글`
- 감지: 스타일 이름이 `바탕글`이 아닌 문단 (예: `본문`, `MS바탕글`, `제목 1`, `제목 2`)
- 수정: 바탕글 스타일 ID로 교체. 글자/문단 모양은 이후 규칙이 명시적으로 지정
- 메모: `문단 스타일이 '{old}'(으)로 설정되어 있어 '바탕글'로 수정했습니다. 다른 문서에서 복사해 오실 때 스타일이 함께 따라오는 경우가 많으니, 붙여넣기 후 F6에서 바탕글로 맞춰 주시면 감사드리겠습니다.`
- 근거: [U][D][F] · 상태: 계획

### R02. 글꼴은 전부 "맑은 고딕"
- 대상: 전체 텍스트 (한글/영문/숫자 등 모든 언어 슬롯)
- 기대값: `fontRef`의 모든 언어 → `맑은 고딕`
- 감지: 다른 글꼴 (예: 제목 앞 공백이 Calibri)
- 수정: 맑은 고딕으로 교체 (fontface에 없으면 추가)
- 메모: `일부 글자가 '{old}' 글꼴로 되어 있어 맑은 고딕으로 수정했습니다.`
- 근거: [T] · 상태: 계획

### R03. 역할별 글자 크기·진하게

| 역할 | 크기 | 진하게 |
|---|---|---|
| CATEGORY | 12pt | O |
| COVER_TITLE | 32pt | O |
| TOC 제목 "목차" | 16pt | X |
| TOC 항목 | 12pt | O |
| COVER_TABLE | 11pt | O |
| H1 | 12pt | O |
| H2 | 12pt | O |
| H3 | 11pt | O |
| H4 | 10pt | X |
| BODY | **10pt** | X (원문에 의도된 부분 강조는 유지 — R03-b) |
| TABLE_CELL | 10pt | 머리행 O / 나머지 원문 유지 (Q 참고) |
| SOURCE | 8pt | X |
| AUTHOR_TAG | 8pt | X |

- R03-a 크기: 다르면 수정. 메모(첫 발생 시 1회): `{size_old}포인트로 되어 있어 {size_new}포인트로 수정했습니다. 그 외에도 {size_old}포인트로 작성된 부분들도 수정했습니다. 앞으로 주의해주시면 감사드리겠습니다.`
- R03-b 진하게: 타이틀 역할은 강제. BODY는 **문단 전체**가 볼드면 해제, 일부 단어만 볼드면 강조로 보고 유지
- 근거: [T][F][D] · 상태: 계획

### R04. 정렬

| 역할 | 정렬 |
|---|---|
| COVER_TITLE, TOC, COVER_TABLE 셀 | 가운데 |
| SOURCE, AUTHOR_TAG | 오른쪽 |
| 그 외 전부 (H1~H4, BODY, EMPTY, OBJECT 등) | **양쪽** |

- 메모: `중간중간 왼쪽 정렬과 양쪽 정렬이 섞여 있었습니다. 양쪽 정렬로 통일해 주시면 감사드리겠습니다.`
- 근거: [U][F][D] · 상태: 계획

### R05. 들여쓰기·여백

| 역할 | 첫 줄 들여쓰기 | 왼쪽 여백 |
|---|---|---|
| CATEGORY, COVER_*, TOC, H1 | 0 | 0 |
| H2, H3, H4, BODY, REFLECTION | **10pt** (`2000`) | 0 |
| SOURCE, AUTHOR_TAG | 0 | 0 |
| OBJECT (표/그림 문단) | **0 (들여쓰기 없음)** | 0 |
| TABLE_CELL | 0 | 0 |

- 메모: `들여쓰기가 {old}pt로 되어 있어 10pt로 수정했습니다. Alt+T(문단 모양)에서 확인하실 수 있습니다.` / 왼쪽 여백: `왼쪽 여백이 {old}pt로 설정되어 있어 0으로 수정했습니다.`
- 근거: [T][D][F] · 상태: 계획

### R06. 문단 위/아래 간격 = 0, 줄 간격 = 160%
- 대상: 전체 (표지 표 포함)
- 기대값: `prev=0`, `next=0`, `lineSpacing PERCENT 160`
- 감지: 그 외 값 (예: 아래 간격 4pt, 줄 간격 110%)
- 메모: `이 부분의 문단 아래 간격이 어째서인지 {val}pt로 설정되어 있었습니다. 아래 간격을 설정하지 않아 주시면 감사드리겠습니다.`
- 근거: [F][D] · 상태: 계획

### R07. 표·그림은 "글자처럼 취급" + 들여쓰기 없음
- 대상: 모든 `hp:tbl`, `hp:pic` (중첩 포함)
- 기대값: `hp:pos@treatAsChar="1"`, 개체가 든 문단 들여쓰기 0
- 메모: `사진(표) 글자처럼 취급 꼭 해주시면 감사드리겠습니다.`
- 근거: [T][F][U] · 상태: 계획

### R08. 출처·각주
- 대상: SOURCE
- 기대값: 바탕글 / 맑은 고딕 / 8pt / 오른쪽 정렬 / 들여쓰기 0 / 진하게 X
- 메모: `출처의 경우 맑은 고딕 8pt, 오른쪽 정렬을 지켜주시면 감사드리겠습니다.`
- 근거: [T][U] · 상태: 계획

### R09. 빈 줄 정리
- R09-a 연속된 빈 줄은 **1줄**로 줄인다 (표지 영역 제외)
- R09-b H2 바로 다음 H3 사이 빈 줄은 **없앤다** (2단위·3단위 타이틀은 붙여 쓴다)
- R09-c 타이틀과 그 본문 사이 빈 줄 없음
- R09-d 블록(H2/H3 단위) 사이는 빈 줄 1줄
- 메모: `이 부분이 너무 많이 띄어져 있었습니다. 한 줄만 띄어주시면 감사드리겠습니다.` / `2단위 타이틀과 3단위 타이틀은 붙여 써 주시면 감사드리겠습니다. 아마 문단 위 문단 아래에 간격 설정이 되어 있고, 바탕글로 설정되지 않아 발생하신 문제인 듯 합니다. Alt T로 확인하고 진행해 주시거나, Alt C 의 문단 모양 복사를 통해 문단 모양이 지켜진 양식에서 복사해 수정해 주시면 감사드리겠습니다.`
- 근거: [F] · 상태: 계획

### R10. 텍스트 앞 불필요한 공백 제거
- 대상: H1~H4, BODY, AUTHOR_TAG
- 감지: 문단 맨 앞 스페이스 (예: `  5. 4장…`, `  직업은…`, ` 1) 소프트웨어…`) — 들여쓰기를 스페이스로 흉내 낸 경우
- 수정: 앞 공백 제거 (들여쓰기는 R05가 담당)
- 근거: 샘플 관찰 · 상태: 계획

### R11. 띄어쓰기·맞춤법
- R11-a 규칙 기반 (확실한 패턴만 자동 수정)
  - `(\S+학과)(\d학년)` → `\1 \2` (예: 경영학과4학년 → 경영학과 4학년)
  - 숫자+단위 등 사전에 등록된 패턴
- R11-b 사전 기반 교정 목록 `rules/spacing_dict.tsv` (예: `직종별유연근무제제안 → 직종별 유연근무제 제안`)
- R11-c 일반 띄어쓰기 교정 엔진 (방식 미정 — Q2)
- 메모: `'{old}'를 '{new}'(으)로 띄어 썼습니다.` (같은 유형은 묶어서 1회)
- 근거: [D][U] · 상태: 계획

### R12. 1단위 타이틀(Ⅰ. Ⅱ.) 쪽 나누기
- 대상: 두 번째 이후의 H1
- 규칙: H1이 시작되는 시점에 **현재 쪽이 이미 50% 넘게 차 있으면**, 그 H1을 다음 쪽에서 시작 (`pageBreak="1"`)
- 50% 이하면 같은 쪽에 이어 쓴다 (Q1에서 확인 필요)
- 쪽 채움 비율은 레이아웃 추정이 필요 (CLAUDE.md "R12 구현 방식" 참고)
- 메모: `1단위 타이틀이 쪽 중간에서 시작되어 다음 쪽으로 넘겼습니다. 앞 내용이 쪽의 절반을 넘기면 Ctrl+Enter로 쪽을 나눠 주시면 더 깔끔하게 보입니다.`
- 근거: [U] · 상태: 계획

### R13. 잘못 가해진 추가 서식 제거 (기본값 복원)
위 규칙이 명시하지 않은 서식도 **양식 기본값과 다르면 기본값으로 되돌린다.**
- 글자 모양: 기울임, 밑줄, 취소선, 글자 색(검정 외), 음영, 장평 ≠ 100%, 자간 ≠ 0, 위/아래 첨자(각주 번호 제외)
- 문단 모양: 오른쪽 여백 ≠ 0, 문단 테두리/배경, "다음 문단과 함께", 줄 나눔 기준 차이
- 예외 목록(유지): 원문 의도로 보이는 부분 볼드(R03-b), 표 머리행 음영(Q 참고), 하이퍼링크
- 메모: 해당 항목명을 넣어 `{항목}이(가) 설정되어 있어 기본값으로 되돌렸습니다.`
- 근거: [U][F] · 상태: 계획

### R14. 표지·목차 일관성 (보기 좋게)
- 목차 항목 텍스트 ↔ 본문 H1 텍스트 일치 검사 → 불일치 시 메모만 (자동 수정 X)
- 표지 정보 표: 가운데 정렬, 11pt 진하게, 셀 내부 문단 간격 0
- 근거: [D][U] · 상태: 계획

## 3. 메모(코멘트) 작성 원칙

[F] 피드백 메모의 문체를 따른다.

1. **현상** — "~로 되어 있었습니다", "~가 섞여 있었습니다"
2. **조치/요청** — "~로 수정했습니다" / "~해 주시면 감사드리겠습니다"
3. **방법 안내(선택)** — "Alt T로 들여쓰기 확인하고…", "Alt C 의 문단 모양 복사를 통해…"
4. **추가 도움(선택, 문서당 1회)** — "혹시 도움이 필요하신 부분이 있으시다면 말씀해주세요."

- 같은 규칙 위반은 **첫 발생 위치에 1회**만 달고 "그 외에도 ~ 부분들도 수정했습니다"로 묶는다
- 메모는 위반된 **텍스트 범위**에 단다 (fieldBegin ~ fieldEnd)
- 작성자(Author)는 설정값 (`config.author`, 기본 `neoju`)
- 메모 문구 템플릿의 원본은 이 문서이며, 코드의 `memo_templates`는 이 문서와 같아야 한다
